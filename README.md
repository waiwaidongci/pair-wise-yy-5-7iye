# 手工织锦纹样方案版本台

直接打开 `index.html` 使用。

## 功能

- 网格绘制：点击填色、拖动连续填色，支持单点 / 十字 / 小菱形纹样块。
- 方案版本：保存时必须填写名称，列表显示网格尺寸（列 × 行）与各色线用量；重名拒绝保存，不会覆盖旧版本。
- 打开旧版本：自动把当前画布留成一条「恢复前备份」版本，再带回该版本的行列数、格子颜色与统计；恢复操作可撤销，撤销即回到恢复前的画布（重做可再次打开）。
- 调整网格：修改行列数后保留新旧画布的重叠区域；若缩小会裁掉已有图案，自动留存一条「缩小前备份」，可从最近版本取回，且调整本身可撤销。
- 用色统计、重复单元预览与断线风险提示始终按当前画布实时重算。
- 导出 JSON：包含当前画布的行列数、格子数据与按当前画布重算的色线用量。

## 数据

- `zfl31Pattern`：当前画布（每次改动自动保存，刷新后继续）。
- `zfl31Versions`：命名版本与自动备份列表（localStorage）。
