# 手工织锦纹样排版台

直接打开`index.html`使用。支持网格绘制、色线统计、撤销重做、方案版本管理和导出JSON。

## 方案版本
- 「保存为版本」需先填写方案名称；重名不能覆盖，需改名或先删除旧版本。
- 版本列表显示每个方案的网格尺寸（列 × 行）、用量总格数和各色线用量，最新的排在最前。
- 「打开」版本前，当前画布会自动留成「恢复前 …」版本；随后带回该版本的行列数、格子颜色和统计。
- 打开版本、调整行列、清空画布都可以撤销，撤销后回到刚才的画布。

## 画布
- 调整行列数会保留重叠区域，缩小不会丢失已保存版本里的图案。
- 缩小裁掉的图案可用「从最近版本取回裁掉的图案」补回：只填充当前空白格，不覆盖已有图案，必要时自动扩回版本尺寸。
- 断线提示、用色统计和导出JSON始终按当前画布重算。
